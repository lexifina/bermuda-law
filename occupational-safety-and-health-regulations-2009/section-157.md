# Applicable safety codes
157 For the purpose of regulation 156(b), the following are the safety codes and the devices to which they are applicable—
(a) Health Canada Safety Code 6 – radio frequency and microwave devices in the frequency range from 3 kHz to 300 GHz;
(b) Health Canada Safety Code 20A - X-ray equipment in medical diagnosis;
(c) Health Canada Safety Codes 23 and 24 - ultrasound equipment;
(d) Health Canada Safety Code 25 - short-wave diathermy equipment;
(e) Health Canada Safety Code 28 – veterinary X-ray equipment;
(f) Health Canada Safety Code 29 - baggage inspection X-ray equipment;
(g) Health Canada Safety Code 30 - dental x-ray equipment;
(h) Health Canada Safety Code 31 - computed tomography equipment;
(i) Health Canada Safety Code 32 - analytical X-ray equipment; and
(j) Health Canada Safety Code 33 – mammography equipment.
