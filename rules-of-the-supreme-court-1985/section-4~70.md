# Property freezing order or interim receiving order made before commencement of claim for recovery order
4 A property freezing order or an interim receiving order which is made before a claim for a recovery order has been commenced shall—
(a) specify a period within which the enforcement authority shall either start the claim or apply for the continuation of the order while the enforcement authority carries out its investigation; and
(b) provide that the order shall be set aside if the enforcement authority does not start the claim or apply for its continuation before the end of that period.
